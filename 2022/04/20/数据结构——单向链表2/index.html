数据结构——单向链表|删除操作

2022-04-20

单向链表|删除

之前已经讨论了介绍了单向链表的基础结构以及它的插入操作，现在来实现单向链表的删除操作。

通过给定节点删除

通过遍历查找实现删除操作可以总结为以下3点：

  • 首先找到删除节点的前驱节点
  • 改变前驱节点所指向的节点
  • 将删除节点的内存释放掉

注意：

因为链表的每一个节点都是动态分配的内存，因此在删除节点的时候务必记得将删除节点的内存释放掉，否则会出现内存泄露的错误

C++实现如下：

//key为需要删除节点的值
void deleteNode(Node** head_ref, int key){
    // 头节点不能丢失
    Node* temp = *head_ref;
    Node* prev = NULL;
	//如果删除节点为头节点，则直接改变头节点，并且释放删除节点内存
    if (temp != NULL && temp->data == key){
        *head_ref = temp->next; 
        delete temp;            
        return;
    }else{ //往下遍历寻找删除节点，记录删除节点的前驱节点是因为prev->next需要指向删除节点的next
    	while (temp != NULL && temp->data != key){
        	prev = temp;
        	temp = temp->next;
    }
	//如果没有找到
    if (temp == NULL)
        return;
    // 找到了，把断掉的地方链接起来
    prev->next = temp->next;
    // 释放内存
    delete temp;
    }
}

通过递归删除指定节点

  • 递归删除指定节点传递的参数是结点指针的引用

  • 由于当前结点指针是从上一个节点的next(由引用传递)传递的，因此如果现在改变了当前指针的值，则前一节点的next也会改变，这正是删除节点所要做的操作

举个栗子：

#include <bits/stdc++.h>

using namespace std;

struct node {
    int info;
    node *link = NULL;

    node() {}

    node(int a)
            : info(a) {
    }
};

void deleteNode(node *&head, int val) {
    if (head == NULL) {
        return;
    }
    // If current node is the node to be deleted
    if (head->info == val) {
        node *t = head;
        head = head->link; // If it's start of the node head node points to second node
        delete (t); // Else changes previous node's link to current node's link
        return;
    }
    deleteNode(head->link, val);
}

void push(node *&head, int data) {
    node *newNode = new node(data);
    newNode->link = head;
    head = newNode;
}

void print(node *head) {
    if (head == NULL) {
        cout << endl;
        return;
    }
    cout << head->info << ' ';
    print(head->link);
}

int main() {
    // Starting with an empty linked list
    node *head = NULL;
    push(head, 10);
    push(head, 12);
    push(head, 14);
    push(head, 15);
    print(head);

    deleteNode(head, 20);
    print(head); // 20 is not present thus no change in the list

    deleteNode(head, 10);
    print(head);

    deleteNode(head, 14);
    print(head);
    return 0;
}

Output:

15 14 12 10
15 14 12 10 
15 14 12 
15 12

通过给定位置删除

给定单向链表和一个位置，删除给定位置的链表节点

Example:

Input: position = 1, Linked List = 8->2->3->1->7
Output: Linked List =  8->3->1->7

Input: position = 0, Linked List = 8->2->3->1->7
Output: Linked List = 2->3->1->7

以下是C++实现栗子：

#include <iostream>

using namespace std;

class Node {
public:
    int data;
    Node *next;
};

//头插法
void push(Node **head_ref, int new_data) {
    Node *new_node = new Node();
    new_node->data = new_data;
    new_node->next = (*head_ref);
    (*head_ref) = new_node;
}

//给定指向头节点的指针和位置（下标）
void deleteNode(Node **head_ref, int position) {
    if (*head_ref == NULL)
        return;
    // 头指针不能改变，以防丢失链表
    Node *temp = *head_ref;
    // 特殊位置0
    if (position == 0) {
        //改变头指针
        *head_ref = temp->next;
        free(temp);
        return;
    }
    // 如果删除节点为中间节点，循环结束后，temp为删除节点的前驱节点
    for (int i = 0; temp != NULL && i < position - 1; i++)
        temp = temp->next;

    // 如果给定位置大于链表长度，则直接退出
    if (temp == NULL || temp->next == NULL)
        return;
    //next为删除节点的后驱节点
    Node *next = temp->next->next;
    //断链,释放内存
    free(temp->next); // Free memory
    //重新链接
    temp->next = next;
}

void printList(Node *node) {
    while (node != NULL) {
        cout << node->data << " ";
        node = node->next;
    }
}

int main() {
    Node *head = NULL;
    push(&head, 7);
    push(&head, 1);
    push(&head, 3);
    push(&head, 2);
    push(&head, 8);

    cout << "Created Linked List: ";
    printList(head);
    deleteNode(&head, 4);
    cout << "\nLinked List after Deletion at position 4: ";
    printList(head);
    return 0;
}

Output:

Created Linked List: 8 2 3 1 7
Linked List after Deletion at position 4: 8 2 3 1

删除整个链表

因为C++没有自动回收内存的机制，所以如果想要删除整个链表，只执行 head=NULL 是不够的，以下为C++实现样例：

void deleteList(Node **head_ref) {
    Node *current = *head_ref;
    Node *next = NULL;
    while (current != NULL) {
        next = current->next;
        free(current);
        current = next;
    }
    *head_ref = NULL;
}
