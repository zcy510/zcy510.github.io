单向链表|插入

在链表头部插入新节点

C++实现代码：

//参数为一个指向头指针的指针，和一个新节点的数据
void push(Node** head_ref, int new_data){
	//创建新节点
	Node* new_node = new Node();
	new_node->data = new_data;
	//新节点应该指向头节点（之前的）
	new_node->next = (*head_ref);
	//新的头节点应该是刚插入的新节点
	(*head_ref) = new_node;
}

在指定节点后面插入新节点

C++实现代码：

//参数为给定插入位置节点，和新节点数据
void insertAfter(Node* prev_node, int new_data){

	// 检查位置节点是否为NULL，如果是的话，就返回，说明参数传错了；前驱节点不能为NULL
	if (prev_node == NULL) {
		return;
	}

	//创建新的节点
	Node* new_node = new Node();
	new_node->data = new_data;
	// 新节点的应该指向prev_node的下一个节点
	new_node->next = prev_node->next;
	//prev_node应该指向新节点
	prev_node->next = new_node;
}

在链表尾部插入新节点

C++实现代码：

//参数为一个指向头指针的指针，和一个新节点的数据
void append(Node** head_ref, int new_data){
	// 创建新节点
	Node* new_node = new Node();
	new_node->data = new_data;
	// 新节点应该指向NULL
	new_node->next = NULL;
	// 判断链表是否为空，如果是，则直接头节点指向新节点，然后返回即可
	if (*head_ref == NULL){
		*head_ref = new_node;
		return;
	}
	//从头节点开始遍历，寻找尾节点
	Node *last = *head_ref;
	while (last->next != NULL){
		last = last->next;
	}
	// 将尾节点指向新节点
	last->next = new_node;
	return;
}
